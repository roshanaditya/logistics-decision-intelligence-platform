# Product Requirements — Draft

## Problem
Logistics teams need a unified interface to explore operational data, estimate transportation costs, optimize warehouse schedules, and retrieve answers from operational documents.

## Initial users
- Transportation planner
- Warehouse operations manager
- Supply-chain analyst

## Planned capabilities
1. Transportation cost prediction
2. Warehouse load scheduling optimization
3. Document-based logistics knowledge retrieval
4. Agentic orchestration across these capabilities

## Phase 1 scope
Reproducible local environment, API skeleton, PostgreSQL, Qdrant, and a basic health check.

## Out of scope
Real client/company data, LLM calls, model training, optimization workflows, authentication, production deployment.
